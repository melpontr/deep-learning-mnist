# Deep Learning on MNIST Dataset
##Περγραφή
Σκοπός της εργασίας είναι η περιγραφή και η εκπαίδευση ενός Βαθιού Νευρωνικού Δικτύου για την ταξινόμηση χειρόγραφων ψηφίων χρησιμοποιώντας το dataset MNIST.
Το dataset περιέχει 60.000 εικόνες εκπαίδευσης και 10.000 εικόνες ελέγχου με χειρόγραφα ψηφία από 0 εώς 9.
##Υλοποίηση
Η εργασία υλοποιήθηκε σε Python με χρήση της βιβλιοθήκης TensorFlow και εκτελέστηκε μέσω Google Colab.
Αρχικά δημιουργήθηκε ένα βασικό νευρωνικό δίκτυο με:
-2 hidden layers
-activation funtion tanh
-softmax output layer
Στη συνέχεια πραγματοποιήθηκε Hyperparameter Tuning δοκιμάζοντας:
-διαφορετικό αριθμό νευρώνων
-Dropout
-διαφορετικές παραμέτρους εκπαίδευσης
##Αποτελέσματα
|     Model    | Accuracy |
|Baseline Model|   93.8%  |
| 512 Neurons  |   94.6%  |
|  Dropout 0.2 |   94.3%  |
Η καλύτερη απόδοση επιτεύχθηκε με 512 νευρώνες ανά hidden layer.
Επομένως, τα βαθιά νευρωνικά δίκτυα μπορούν να επιτύχουν πολύ καλή ακρίβεια ακόμα και σε σχετικά απλά datasets όπως το MNIST. Η αλλαγή των hyperparameters επηρεάζει σημαντικά την απόδοση του μοντέλου.
